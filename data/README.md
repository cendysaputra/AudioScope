# data/

Local datasets live here and are never committed. Download ESC-50 with:

```bash
python -m audioscope.data.download --dataset esc50 --dest data/esc50
```

ESC-50 is distributed by its author under a Creative Commons non-commercial
license (see https://github.com/karolpiczak/ESC-50). UrbanSound8K must be
requested from its own page and unpacked to `data/urbansound8k/`.
